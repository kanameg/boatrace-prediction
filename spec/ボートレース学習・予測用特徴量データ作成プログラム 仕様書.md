# ボートレース予測用特徴量データ作成プログラム 仕様書

## 概要

ボートレースの予測モデル学習・推論に使用する特徴量データを生成するPythonプログラム。
学習用データと予測用データを同一スクリプトから生成できる。

---

## ファイル構成

```
make_data.py          # メインスクリプト
data/
  programs.csv        # 入力: レースプログラム情報
  results.csv         # 入力: レース結果情報
  racers.csv          # 入力: 選手情報（コース別統計含む）
  processed/
    train_data.csv    # 出力: 学習用特徴量データ
    pred_data.csv     # 出力: 予測用特徴量データ
```

---

## 実行方法 (CLI)

### 学習用データ生成

```bash
python make_data.py train --start 2025-01-01 --end 2025-12-31
```

| 引数 | 型 | 必須 | 説明 |
|------|----|------|------|
| `--start` | `str` (YYYY-MM-DD) | ○ | 学習データの開始日 |
| `--end` | `str` (YYYY-MM-DD) | ○ | 学習データの終了日 |

### 予測用データ生成

```bash
python make_data.py pred --date 2026-02-22
```

| 引数 | 型 | 必須 | 説明 |
|------|----|------|------|
| `--date` | `str` (YYYY-MM-DD) | ○ | 予測対象日 |

## データ処理フロー

### 共通前処理

1. **日付列生成**: `年`, `月`, `日` → `開催日`（datetime型）
2. **レースID生成**: `年(4桁)+月(2桁)+日(2桁)+レース場番号(2桁)+レース番号(2桁)` の12桁文字列
3. **距離フィルタ**: 1800m のみに絞り込む

### 学習用データ生成（trainモード）

1. `results.csv` を読み込み、指定期間（`--start` 〜 `--end`）でフィルタリング
2. 着順が `F`, `S0`, `S1`, `S2`, `L0`, `L1`, `K0`, `K1` の行を除外（フライング・失格）
3. 着順を整数に変換
4. `programs.csv` を読み込み、レースIDで結果データとマージ
5. 特徴量を計算（後述）
6. 目的変数 `1着フラグ`（着順==1 なら1、それ以外0）を追加
7. `data/processed/train_data.csv` に保存

### 予測用データ生成（predモード）

1. `programs.csv` を読み込み、指定日（`--date`）でフィルタリング
2. 特徴量を計算（後述、結果データを使わない項目のみ）
3. `data/processed/pred_data.csv` に保存

## 特徴量仕様

### レースキー情報（出力に含めるがモデル学習には使用しない）

| カラム名 | 説明 |
|----------|------|
| レースID | 12桁レース識別子 |
| 選手登番 | 選手登録番号 |
| 艇番 | 艇番（1〜6） |

### プログラム由来の特徴量（programs.csv から作成、予測時も使用可能）

以下の値について「**レース内の平均との差**」を特徴量とする。
これにより、同一レース内での相対的な強さを表現する。

| カラム名 | 元データ | 説明 |
|----------|----------|------|
| 全国勝率差 | 全国勝率 | レース内全国勝率 − レース平均全国勝率 |
| 全国2連率差 | 全国2連率 | レース内全国2連率 − レース平均全国2連率 |
| 当地勝率差 | 当地勝率 | レース内当地勝率 − レース平均当地勝率 |
| 当地2連率差 | 当地2連率 | レース内当地2連率 − レース平均当地2連率 |
| モーター2連率差 | モーター2連率 | レース内モーター2連率 − レース平均 |
| ボート2連率差 | ボート2連率 | レース内ボート2連率 − レース平均 |

以下は差分でなくそのままの値または変換値を使用する。

| カラム名 | 元データ | 説明 |
|----------|----------|------|
| 艇番 | 枠番 | 1〜6（内側ほど有利） |
| 級別コード | 級別 | A1=4, A2=3, B1=2, B2=1 に数値変換 |
| 級別差 | 級別コード | レース内級別コード − レース平均級別コード |

### 選手情報由来の特徴量（racers.csv から作成、予測時も使用可能）

racers.csv は選手登番でマージする。racers.csv には同一選手の複数年・複数期のデータが含まれるため、**各選手について `年` と `期` が最大のレコード（最新データ）を1件だけ使用する**。マージ前に選手登番ごとに最新レコードへ絞り込んでおくこと。

| カラム名 | 元データ | 説明 |
|----------|----------|------|
| 能力指数差 | 今期能力指数 | レース内能力指数 − レース平均能力指数 |
| 平均ST差 | 平均スタートタイミング | レース内平均ST − レース平均ST（値が小さいほど良い） |
| コース別複勝率 | Nコース複勝率 | 出走艇番と一致するコースの複勝率 |
| コース別ST差 | Nコース平均スタートタイミング | 出走艇番のコース別平均ST − レース内平均ST |

### 結果データ由来の特徴量（results.csv から作成、**学習時のみ**）

以下は結果データから計算するため、予測時には使用しない。

| カラム名 | 元データ | 説明 |
|----------|----------|------|
| 展示タイム差 | 展示 | レース内展示タイム − レース平均展示タイム（値が小さいほど良い） |
| スタートタイミング差 | スタートタイミング | レース内ST − レース平均ST |
| 進入コース | 進入 | 実際の進入コース（1〜6） |

---

## 実装上の注意点

- `data/processed/` ディレクトリが存在しない場合は自動作成すること
- racers.csv のマージ時、対応する選手データが見つからない場合は NaN とする（行削除しない）
- レースIDは文字列型として保持する
- programs.csv の `枠番` は `艇番` に列名を変更して使用する
- 処理開始・終了時にログを出力し、生成行数を表示すること
