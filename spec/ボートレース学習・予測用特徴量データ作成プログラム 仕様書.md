# ボートレース学習・予測用特徴量データ作成プログラム 仕様書

## 概要

ボートレースの予測モデル（LightGBM）の学習・推論に使用する特徴量データを生成するPythonプログラム。
学習用データと予測用データを同一スクリプトから生成できる。

**設計原則:**
- 各レース内の1着を予測するため、**特徴量はレースID内での選手同士の相対的な差分を中心に作成する**
- **生値は特徴量として使用しない**。差分特徴量（自選手の値 − レース内平均値）のみを使用する
- 目的変数（`1着フラグ`）を除き、学習用・予測用の特徴量は完全に一致させる
- 予測時に入手できないデータ（レース本番中の計測値）は特徴量に使用しない
- LightGBMでの学習に適したデータ形式で出力する

---

## ファイル構成

```
make_data.py              # メインスクリプト
data/
  raw/
    programs.csv          # 入力: レースプログラム情報
    results.csv           # 入力: レース結果情報
    racers.csv            # 入力: 選手情報（コース別統計含む）
  processed/
    train_data.csv        # 出力: 学習用特徴量データ
    pred_data.csv         # 出力: 予測用特徴量データ
```

---

## 実行方法 (CLI)

### 学習用データ生成

```bash
python make_data.py train --start 2025-01-01 --end 2025-12-31
```

| 引数 | 型 | 必須 | 説明 |
|------|----|------|------|
| `--start` | `str` (YYYY-MM-DD) | ○ | 学習データの開始日（以上） |
| `--end` | `str` (YYYY-MM-DD) | ○ | 学習データの終了日（以下） |

### 予測用データ生成

```bash
python make_data.py pred --date 2026-02-22
```

| 引数 | 型 | 必須 | 説明 |
|------|----|------|------|
| `--date` | `str` (YYYY-MM-DD) | ○ | 予測対象日 |

## データ処理フロー

### 共通前処理

1. **日付列生成**: `年`, `月`, `日` → `開催日`（datetime型）
2. **レースID生成**: `年(4桁)+月(2桁)+日(2桁)+レース場番号(2桁)+レース番号(2桁)` の12桁文字列（str型）
3. **距離フィルタ**: 1800m のみに絞り込む
4. **racers.csv の最新化**: `年`・`期` で降順ソートし、選手登番ごとに先頭1件（最新データ）を使用する

### 学習用データ生成（trainモード）

1. `results.csv` を読み込み、共通前処理を実施
2. 指定期間（`--start` 〜 `--end`）でフィルタリング
3. 着順が `F`, `S0`, `S1`, `S2`, `L0`, `L1`, `K0`, `K1` の行を除外（フライング・失格）
4. 残った行の着順を整数に変換
5. `programs.csv` を読み込み、レースID・選手登番・艇番でマージ
6. `racers.csv` を読み込み（最新化済み）、選手登番でマージ
7. 特徴量を計算（後述）
8. 目的変数 `1着フラグ`（着順==1 なら1、それ以外0）を末尾に追加
9. `data/processed/train_data.csv` に保存

### 予測用データ生成（predモード）

1. `programs.csv` を読み込み、共通前処理を実施
2. 指定日（`--date`）でフィルタリング
3. `racers.csv` を読み込み（最新化済み）、選手登番でマージ
4. 特徴量を計算（後述）
5. `data/processed/pred_data.csv` に保存

## 特徴量仕様

各レースでの1着予測を目的とするため、**レースID内の選手同士の相対的な差分特徴量を主軸に設計する**。
差分 = 自選手の値 − 同一レース（レースID）内の平均値。

### レースキー情報（出力に含めるがモデル学習には使用しない）

| カラム名 | 型 | 説明 |
|----------|----|------|
| レースID | str | 12桁のレース識別子 |
| 選手登番 | int | 選手登録番号 |

### A. カテゴリ特徴量（`category` dtype で出力）

差分では表現できない絶対的な位置情報をカテゴリとして保持する。

| カラム名 | 元データ | 説明 |
|----------|----------|------|
| 艇番 | 枠番 | 1〜6。内側ほど1着に有利 |
| レース場番号 | レース場番号 | 1〜24。場ごとにコースの有利不利が異なる |
| 級別コード | 級別 | A1=4, A2=3, B1=2, B2=1 に変換 |

### B. 主特徴量：レース内差分（programs.csv 由来）

| カラム名 | 元データ | 説明 |
|----------|----------|------|
| 全国勝率差 | 全国勝率 | 自選手の全国勝率 − レース内平均全国勝率 |
| 全国2連率差 | 全国2連率 | 自選手の全国2連率 − レース内平均 |
| 当地勝率差 | 当地勝率 | 自選手の当地勝率 − レース内平均 |
| 当地2連率差 | 当地2連率 | 自選手の当地2連率 − レース内平均 |
| モーター2連率差 | モーター2連率 | 自選手のモーター2連率 − レース内平均 |
| ボート2連率差 | ボート2連率 | 自選手のボート2連率 − レース内平均 |
| 級別差 | 級別コード | 自選手の級別コード − レース内平均 |

### C. 主特徴量：レース内差分（racers.csv 由来）

racers.csv は選手登番ごとに最新期のレコードをマージして使用する。

| カラム名 | 元データ | 説明 |
|----------|----------|------|
| 能力指数差 | 今期能力指数 | 自選手の能力指数 − レース内平均 |
| 平均ST差 | 平均スタートタイミング | 自選手の平均ST − レース内平均（小さいほど速い） |
| コース別複勝率差 | Nコース複勝率 | 出走艇番Nに対応するコース複勝率 − レース内平均 |
| コース別ST差 | Nコース平均スタートタイミング | 出走艇番Nに対応するコース別平均ST − レース内平均 |

### D. results.csv から作成する選手能力特徴量（オプション）

レース結果を集計して選手ごとの実績指標を作成できる。
**データリーク防止のため、各レースの開催日より前の結果のみを集計すること。**
予測時は予測対象日より前の全結果を集計する。

| カラム名 | 説明 |
|----------|------|
| 直近N戦勝率差 | 選手の直近N戦勝率 − レース内平均（N=30程度） |
| 直近N戦複勝率差 | 選手の直近N戦複勝率 − レース内平均 |
| 直近N戦平均着順差 | 選手の直近N戦平均着順 − レース内平均 |
| 直近N戦平均ST差 | 選手の直近N戦平均ST − レース内平均 |

## LightGBM向け実装上の注意点

- **カテゴリ変数**: `艇番`, `レース場番号`, `級別コード` は pandas の `category` dtype で出力する。LightGBM 学習時に `categorical_feature` パラメータで指定して使用する
- **欠損値**: LightGBM はツリー分岐時に NaN を内部処理できるため、欠損値の補完は行わない。マージで対応レコードが見つからない場合も NaN のまま行を保持する
- **スケーリング不要**: LightGBM はツリーベースのため、特徴量の正規化・標準化は不要
- **特徴量の一致**: train と pred の特徴量カラム（列名・順序）は完全一致させること
- **入力パス**: `data/raw/` 以下の CSV を読み込む
- **出力先**: `data/processed/` ディレクトリが存在しない場合は自動作成する
- **レースID**: str 型として保持する（数値変換しない）
- **programs.csv の `枠番`**: 読み込み後に `艇番` へ列名を変更して使用する
- **処理ログ**: 処理開始・終了時にログを出力し、生成行数を表示する
