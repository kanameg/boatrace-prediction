## レーサー期別成績変換プログラム仕様書

### 概要
このプログラムは、ボートレースのレーサー期別成績を読み込み、CSV形式に変換するためのプログラム仕様書です。入力ファイルはUTF-8エンコーディングの固定位置にデータが入ったテキストデータで、出力はCSV形式で行います。

### プログラム言語
python 3.10

### ファイル名
`convert_racer_record.sh`

### 実行方法
```bash
./convert_racer_record.sh [e|l] YYYY
```
ここで、`YYYY`は年（4桁）、eは前期、lは後期を指定します。

### 入力ファイル
- 入力ファイル名: `racer_{YYYY}{e|l}.txt`
- 入力ファイルのディレクトリ: `data/raw/racer_records/`
- 入力ファイルのエンコーディング: UTF-8
- 入力ファイルのフォーマット: 固定位置のテキストデータ

### 出力ファイル

- 出力ファイルのディレクトリ: `data/`
- 出力ファイルのエンコーディング: UTF-8
- 出力ファイルのフォーマット: CSV形式

### データ変換処理
各項目について以下の変換処理を行います：

1. **数値データ**: 先頭の0を除去して整数に変換
2. **小数点データ**: 
   - 勝率: 4桁 → 小数点以下2桁（例: 0756 → 7.56）
   - 複勝率: 4桁 → 小数点以下1桁（例: 0459 → 45.9）
   - 平均スタートタイミング: 3桁 → 小数点以下2桁（例: 016 → 0.16）
   - 平均スタート順位: 3桁 → 小数点以下2桁（例: 240 → 2.40）
   - 能力指数: 4桁 → 小数点以下2桁（例: 7400 → 74.00）
3. **生年月日**: 年号を使って西暦に変換
4. **名前漢字**: 1文字の全角スペースを削除、2文字以上の全角スペースは半角スペースに変換
5. **名前カナ**: 半角カタカナを全角カタカナに変換
6. **出身地**: 全角スペースを削除
